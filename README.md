# GCSE Homeschool Planner & Tracker (Education42)

An installable Progressive Web App (PWA) tailored for Year 10 GCSE homeschool planning. 

## Features
- **Curriculum Architecture**: 36-week four-day modular timetable (English, Maths, Biology, Chemistry, Physics, Art, PSHE/RSE).
- **Offline Capable**: Uses a Service Worker to cache assets, running completely without an internet connection.
- **Local Persistence**: Saves completed tasks and diary entries automatically to browser storage.
- **Downloadable/Installable**: Installs directly to desktop or mobile home screens without an app store.
